# DecodeLabs AI Project 2: Iris Flower Classification 🌸

## 📌 Project Overview
This project focuses on Data Classification Using Artificial Intelligence through supervised machine learning. The K-Nearest Neighbors (KNN) algorithm is used to classify Iris flowers based on their physical measurements.

## 🎯 Objectives
- Understand the Iris dataset.
- Split data into training and testing sets.
- Apply feature scaling.
- Train a KNN classification model.
- Evaluate model performance.

## 🛠️ Technologies Used
- Python
- Scikit-learn
- Pandas
- Matplotlib

## 📊 Dataset
The Iris dataset contains 150 samples, four flower measurements, and three species:
- Setosa
- Versicolor
- Virginica

## ⚙️ Methodology
1. Load the Iris dataset.
2. Split the data into training and testing sets.
3. Standardize the features.
4. Train the KNN model with k = 5.
5. Predict flower species.
6. Evaluate the model using accuracy, a confusion matrix, and the F1 score.

## 🚀 How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the program:

```bash
python iris_classification.py
```

## ✅ Project Outcome
Implemented a supervised machine learning workflow to classify Iris flowers and evaluate prediction performance.
